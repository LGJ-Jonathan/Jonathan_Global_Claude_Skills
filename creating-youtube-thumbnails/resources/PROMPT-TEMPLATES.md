# AI Prompt Templates for YouTube Thumbnails

## Freepik Prompt Templates (Google Nano Banana Pro)

### Template 1: Person with Emotion + Environment
```
A [age] [gender] [ethnicity descriptor if needed] with [hair description]
wearing [clothing], [exact expression — e.g., eyes wide open in shock, mouth
slightly open, eyebrows raised], [exact pose — e.g., both hands on cheeks,
leaning forward, arms crossed].
[Lighting — e.g., dramatic side lighting from the left, warm golden hour light,
studio ring light creating catch lights in eyes].
[Background — e.g., standing in front of a massive pile of cash, on the edge
of a cliff overlooking the ocean, in a destroyed room].
Shot on Canon EOS R5, 85mm f/1.4 lens, shallow depth of field, bokeh background.
Photorealistic, editorial photography, vibrant colors, high contrast.
16:9 aspect ratio.
```

### Template 2: Person + Oversized Object (Scale Play)
```
A [person description matching @image1] standing next to a [impossibly large
object — e.g., 10-foot tall burger, car-sized diamond, house-sized shoe].
The person is [reaction — e.g., looking up in awe, reaching out to touch it,
pointing at it with excitement]. The [object] towers over them, emphasizing
the massive scale difference.
[Lighting — even, bright, slightly warm studio-style lighting].
[Background — clean, slightly blurred, single color gradient or simple environment].
Photorealistic, vibrant, commercial photography style. 16:9 aspect ratio.
```

### Template 3: Before/After Split
```
A split composition showing the same [person from @image1]:
Left side: [the "before" state — e.g., messy hair, tired expression, dark dingy
room, wearing old clothes, muted desaturated colors].
Right side: [the "after" state — e.g., perfect hair, confident smile, luxury
penthouse, wearing a suit, vibrant saturated colors].
A clear visual divide runs down the center. Strong contrast between both sides.
Photorealistic, editorial style, dramatic lighting. 16:9 aspect ratio.
```

### Template 4: Action Freeze Frame
```
[Person from @image1] captured mid-[action — e.g., jumping over a gap between
two buildings, catching a ball of fire, falling backwards into water].
[Expression — e.g., face showing pure determination, eyes locked on target].
Motion blur on extremities, frozen peak moment.
[Environment — e.g., city rooftop at sunset, stadium full of people, underwater].
Dynamic camera angle — [e.g., low angle looking up, Dutch angle, over-the-shoulder].
Photorealistic, high-speed photography style, cinematic. 16:9 aspect ratio.
```

### Template 5: Cinematic Poster Style
```
[Person from @image1] in a [powerful pose — e.g., standing with arms crossed,
looking down at camera, silhouetted against bright background].
[Cinematic lighting — e.g., dramatic rim lighting in blue and pink, single
spotlight from above, backlit with lens flare].
[Atmospheric elements — e.g., smoke/haze drifting through scene, rain falling,
dust particles in light beams, sparks].
[Background — e.g., dark moody gradient, futuristic cityscape, foggy forest].
Movie poster composition, cinematic color grading, film grain.
Shot on Arri Alexa, anamorphic lens. 16:9 aspect ratio.
```

### Template 6: Outdoor/Adventure Realistic
```
[Person from @image1] [outdoor action — e.g., standing at the summit of a
snowy mountain, walking through a dense jungle, sitting in a kayak on crystal
clear water].
Midday outdoor direct sunlight casting soft shadows on the face.
Natural environment with real texture and depth.
[Weather/atmosphere — e.g., light snow falling, golden hour warm light,
overcast dramatic sky].
Photorealistic, National Geographic style, natural colors. 16:9 aspect ratio.
```

## ChatGPT Prompt-for-Prompt Templates

Use these when asking ChatGPT to write a Freepik prompt for you:

### Basic Request
```
I need a prompt for Freepik. The images I'm uploading are reference images.
@image1 is a photo of [me/my client] — keep their face and appearance identical.
@image2 is a pose reference — match this exact pose.

Create a prompt where [describe the scene you want].

The thumbnail is for a YouTube video titled "[video title]".
The emotion should be [specific emotion].
The style should be [MrBeast clean / realistic raw / cinematic].
```

### Iteration Request (Feed Back Generations)
```
Here are the images Freepik generated [attach screenshot].
I [scribbled out / marked] the ones I don't like.
The ones I do like are [describe which and why].

Revise the prompt to:
- [specific change 1 — e.g., make the person more muscular]
- [specific change 2 — e.g., change background to outdoor]
- [specific change 3 — e.g., more dramatic lighting]

Keep everything else the same.
```

### Style Transfer Request
```
I need a prompt for Freepik.
Don't change anything about the person in @image1.
Just change the lighting to resemble [lighting description — e.g.,
midday outdoor direct sunlight casting soft shadows on the face /
dramatic blue and pink neon rim lighting / warm golden hour backlight].
```

## PoseMyArt Workflow

1. Go to posemy.art → Open Pose My Art
2. Click the 3D model → colored circles appear at joints
3. Rotate/position joints to desired pose
4. Use pre-made poses library for speed (top-left icons)
5. Add props if needed (barrels, chairs, tables)
6. Screenshot the final pose
7. Use screenshot as `@image2` (pose reference) in your Freepik prompt
8. Prompt should say: "Match the exact body pose shown in @image2"

**Important:** Upload reference images to Freepik in the SAME ORDER as referenced in the prompt (@image1 = first upload, @image2 = second upload).

## Quick Prompt Modifiers

Add these to any prompt to adjust style:

| Modifier | Effect |
|----------|--------|
| `vibrant colors, high saturation` | MrBeast pop style |
| `natural colors, film grain` | Realistic raw style |
| `cinematic color grading, teal and orange` | Movie poster style |
| `shallow depth of field, bokeh` | Subject isolation |
| `low angle, looking up at subject` | Power/authority feel |
| `high angle, looking down` | Vulnerability/small feel |
| `Dutch angle, 15 degrees tilted` | Tension/unease |
| `extreme close-up, face fills frame` | Emotional impact |
| `wide shot, person small in frame` | Scale/environment emphasis |
| `backlit, silhouette edges` | Drama/mystery |
| `rim lighting in [color]` | Subject separation |
| `volumetric light, god rays` | Epic/spiritual feel |
| `motion blur on [element]` | Speed/action |
| `lens flare` | Cinematic polish |
